# Plantilla de Rol — NO MODIFICAR ESTE ARCHIVO

Cada miembro del equipo debe crear su archivo correspondiente (`rol_lider.md`, `rol_dev01.md`, etc.)
copiando la estructura de abajo y llenando con su información real.

---

## Formato Requerido

El archivo debe contener **exactamente** estas secciones (los encabezados `##` deben ser idénticos):

```markdown
## Datos del Miembro

- **Nombre:** [Tu nombre]
- **Rol asignado:** [Líder / Analista / Desarrollador / QA]
- **Usuario de GitHub:** [tu-usuario]

## Descripción del Rol

[Párrafo describiendo qué hace este rol dentro del equipo.
Mínimo 2 oraciones.]

## Responsabilidades

- [Responsabilidad 1]
- [Responsabilidad 2]
- [Responsabilidad 3]
```

---

**Reglas:**
1. El archivo debe empezar con `## Datos del Miembro` (sin `#` de título nivel 1).
2. Las 3 secciones son **obligatorias**: `Datos del Miembro`, `Descripción del Rol`, `Responsabilidades`.
3. No dejar los valores entre corchetes `[...]` sin reemplazar.
