## Descripción del Rol

El rol de Quality Assurance (QA) es fundamental para garantizar que cada feature desarrollada cumpla con las reglas de negocio y los estándares de calidad definidos. Se encarga de diseñar, ejecutar y automatizar pruebas tanto en el frontend como en el backend para detectar fallos tempranamente.

## Responsabilidades

- Diseñar y ejecutar planes de pruebas unitarias, de integración y de extremo a extremo (E2E).
- Reportar, documentar y realizar el seguimiento de errores o bugs encontrados durante el desarrollo.
- Validar que cada incremento de software (feature) cumpla estrictamente con los criterios de aceptación antes de su integración a producción.
